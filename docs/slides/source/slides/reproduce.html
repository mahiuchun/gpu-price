Everything in this deck can be rebuilt. The main script needs only uv and the data pack; it checks scorer parity, rebuilds the forecast from the recorded agent answers and prints hashes. The backtest flag replays the AI scientist’s recorded ideas through the blind test and reproduces its table exactly. Fresh AI runs need keys and will not repeat word for word, which is why every answer is saved.
