HOW IT WORKS

Four forecasters, several ways to improve them, one fixed referee

Data, cut by date

Each research step runs in its own Modal container that holds only data up to that step’s date.

Loops propose changes

A change is kept only if it helps on practice days and passes a hidden check.

The referee is fixed

Scoring matches the starter kit’s scorer; the AI cannot touch it.
