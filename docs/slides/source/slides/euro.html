Some of what looks like repricing is the exchange rate. One provider prices in euros and the tracking site converts to dollars each morning, so its dollar price moves Tuesday to Saturday and stands still on Sunday and Monday, whatever happens to GPU demand. An AI analyst that writes and runs its own tests found a wider version of this weekday pattern in three scored cloud spot prices. A simple rule built on it did not improve the forecasts.
