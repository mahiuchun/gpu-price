Percent less error than drift · FINDINGS.md §11

The same five-agent crew, answered by other models, on the same 479 fresh forecasts. Every API model cut error by 15% to 22% against drift, including one whose whole run cost 17 cents, and none is clearly better or worse than the crew’s own model. Only the untrained open model fell clearly behind. The coach’s two changes were chosen while working with gpt-6.1-sol; they carry over to the other GPT models and to the open model, but not to Claude, whose ranges already held about 80% of the time. No rule was written before this ran, and each model was run once.
